## 🌟 Mga Bagong Tampok at Enhancement (Upgraded Features)

1. **Cyber-Engineering Dark UI:**
   - Inspirado sa circuit boards, microcontrollers, at digital systems.
   - Dynamic PCB background grid, glowing test nodes, at animated MCU chip (`ATmega / ARM`).
   - Pure HTML5, CSS3, at Vanilla JavaScript (walang mabibigat na frameworks, mabilis mag-load).

2. **Interactive CLI Terminal (Command Prompt) `argie@cpe:~$`:**
   - Matatagpuan sa Terminal section ng site.
   - Pwedeng mag-type ng mga commands tulad ng:
     - `help` — Listahan ng mga utos.
     - `neofetch` — Nagpi-print ng Computer Engineering specs at telemetry.
     - `projects` — Ipinapakita ang 4 na pangunahing builds.
     - `skills` — Hardware, firmware, at software toolkit.
     - `about` — Background at layunin ni Argie.
     - `contact` — Email, location, at GitHub info.
     - `matrix`, `date`, `clear` — Interactive console utilities.
   - May mga clickable quick-chips para madaling gamitin kahit sa cellphone!

3. **Interactive Digital Logic Gate Simulator:**
   - Makikita sa **Logic Demo** section.
   - Pwedeng mag-switch ng mga gate: **AND (7408)**, **OR (7432)**, **XOR (7486)**, **NAND (7400)**, **NOR (7402)**.
   - Pindutin ang **Input A** at **Input B** switches (0 o 1) upang makita ang totoong pag-ilaw ng simulated LED (+5V) at real-time update sa **Truth Table**!

4. **Detailed Project Modals (5 Featured Builds):**
   - **Community Aid Network (CAN) – Project Nexus** (Capstone Web Platform, ICCT Colleges, Lead Backend Developer, may kasamang PDF viewer/download).
   - **Smart Automated Coin Changer Machine** (Hardware + Embedded, pulse counting, power step-down 12V to 5V, greedy payout algorithm).
   - **Digital Logic Circuits & Combinational Systems** (TTL/CMOS, K-maps, simulation).
   - **Microcontroller Sensor System** (ESP32/Arduino, ultrasonic, I2C OLED, non-blocking timing).
   - **Object-Oriented Java Software Suite** (OOP Architecture, File I/O, CRUD operations).

5. **Direct Contact Channels & Toast Notifications:**

   - Direktang clickable call/SMS link at GitHub profile (`https://github.com/ArgieEtac`).

6. **Profile Photo & Quick CV Brief:**
